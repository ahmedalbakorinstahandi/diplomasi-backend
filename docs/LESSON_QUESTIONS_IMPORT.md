# استيراد أسئلة الدرس (Import Lesson Questions)

هذا الـ endpoint يسمح لك بإضافة أو استبدال جميع أسئلة الدرس (اختيار من متعدد، صح/خطأ، توصيل) دفعة واحدة باستخدام JSON، مع تحديد الإجابات الصحيحة.

---

## الـ Endpoint

| الطريقة | المسار | الوصف |
|--------|--------|--------|
| `POST` | `/api/v1/admin/lessons/{id}/import-questions` | استيراد أسئلة لدرس موجود (id = lesson_id). |

- يحتاج لصلاحية تحديث الدروس (نفس صلاحيات تعديل الدرس).

---

## هيكل الـ Body

```json
{
  "replace": true,
  "questions": [
    {
      "type": "single_choice",
      "text": "نص السؤال...",
      "score": 1,
      "explanation": "شرح اختياري يظهر بعد الإجابة.",
      "options": [
        { "text": "خيار 1", "is_correct": false },
        { "text": "خيار 2", "is_correct": true }
      ]
    }
  ]
}
```

### الحقول

- **`replace`** (اختياري، Boolean):
  - إذا كانت `true` يتم حذف جميع أسئلة الدرس القديمة واستبدالها بالجديدة.
  - إذا لم تُرسل أو `false` يتم إضافة الأسئلة فوق الموجودة (مع الحفاظ على الأسئلة القديمة).

- **`questions`** (مطلوب، Array):
  - مصفوفة الأسئلة. كل عنصر يمثل سؤالاً واحداً.

داخل كل عنصر من `questions`:

| الحقل | مطلوب | الوصف |
|-------|--------|--------|
| `type` | نعم | نوع السؤال: `single_choice`, `multiple_choice`, `true_false`, `match`. |
| `text` | نعم | نص السؤال. |
| `score` | لا | درجة السؤال (افتراضي 1 عند التصحيح إذا لم تُرسل). |
| `explanation` | لا | شرح/تعليق يظهر بعد الإجابة. |

#### 1. أسئلة الاختيار من متعدد / صح وخطأ

لأنواع: `single_choice`, `multiple_choice`, `true_false` نستخدم `options`:

```json
{
  "type": "single_choice",
  "text": "في أي مرحلة من مراحل التفاوض، يتم طرح أسئلة ذكية، والإصغاء للطرف الآخر، والتلخيص لفهم أولويات الطرف الآخر؟",
  "score": 1,
  "options": [
    { "text": "التحضير", "is_correct": false },
    { "text": "تبادل المعلومات", "is_correct": true },
    { "text": "المساومة الصريحة", "is_correct": false },
    { "text": "الالتزام", "is_correct": false }
  ]
}
```

- في `single_choice` / `true_false`: يجب أن تكون إجابة صحيحة واحدة فقط (`is_correct: true` لعنصر واحد).
- في `multiple_choice`: يمكن أن يكون أكثر من خيار صحيح، ويتم التقييم حسب منطق الـ service الحالي.

#### 2. أسئلة صح/خطأ

تمثَّل كـ `true_false` مع خيارين فقط (صح / خطأ)، وتحديد الصحيح بـ `is_correct`:

```json
{
  "type": "true_false",
  "text": "التفاوض هو مناقشة أرقام وأسعار، وليس منظومة علاقات.",
  "score": 1,
  "options": [
    { "text": "صح", "is_correct": false },
    { "text": "خطأ", "is_correct": true }
  ]
}
```

#### 3. أسئلة التوصيل (`match`)

في حالة `match` نستخدم **قائمة خيارات مسطّحة**، وكل خيار يحتوي:

- `text`: نص العنصر (العمود أ أو العمود ب).
- `pair_key`: رمز الربط مثل `p1`, `p2`, `p3`...

كل **زوج مترابط** (عنصر من العمود أ + عنصر من العمود ب) يجب أن يكون له **نفس `pair_key`**.  
الربط بين العناصر يُفهم **فقط من خلال المفتاح**؛ ترتيب الظهور في الواجهة أو في النص الأصلي لا يغيّر التصحيح.

**ترتيب العناصر في المصفوفة `options`:**

1. **أولاً**: كل عناصر **العمود (أ)** بالترتيب الذي تريده (مثلاً 1، 2، 3، 4، 5)، مع تعيين `pair_key` لكل واحد (p1، p2، …).
2. **ثانياً**: كل عناصر **العمود (ب)** بالترتيب الذي تريده — ويمكن أن تكون **مخربطة عمداً** (أ، ب، ج، د، و بترتيب مختلف عن العمود أ) حتى يختار المستخدم الربط الصحيح. الربط الصحيح يُحدَّد فقط من خلال تطابق `pair_key`.

النظام يحفظ العناصر **بنفس ترتيب الإرسال** في قاعدة البيانات؛ التصحيح يعتمد على تطابق `pair_key` بين العنصرين المختارين فقط.

> **أفضل ممارسة**:  
> - استخدم مفاتيح متسلسلة: `p1`, `p2`, `p3`, ... لكل سؤال.  
> - لا تكرر نفس `pair_key` أكثر من مرتين في نفس السؤال (عنصر في العمود أ + عنصر في العمود ب).

**مثال مطابق للنص (عمود أ أولاً، ثم عمود ب مخربط — الربط عبر المفتاح فقط):**

- العمود (أ): 1. التجنب → p1، 2. الإرضاء/الملاءمة → p2، 3. المساومة/التناصف → p3، 4. التنافس → p4، 5. التعاون/حل المشكلات → p5.
- العمود (ب): أ → p5، ب → p3، ج → p4، د → p1، و → p2 (مخربطين عمداً؛ الربط الصحيح من خلال `pair_key` فقط).

```json
{
  "type": "match",
  "text": "صل الأسلوب التفاوضي في العمود (أ) بما يناسبه من وصف في العمود (ب):",
  "score": 5,
  "options": [
    { "text": "التجنب", "pair_key": "p1" },
    { "text": "الإرضاء / الملاءمة", "pair_key": "p2" },
    { "text": "المساومة / التناصف", "pair_key": "p3" },
    { "text": "التنافس", "pair_key": "p4" },
    { "text": "التعاون / حل المشكلات", "pair_key": "p5" },

    { "text": "يفتش عن خيارات \"توسع الكعكة\"، ويحتاج إلى ثقة، وقت، وخيال.", "pair_key": "p5" },
    { "text": "ينجز الاتفاق بسرعة بقاعدة \"نقسم الفرق\"، لكنه لا يكتشف حلولاً إبداعية.", "pair_key": "p3" },
    { "text": "يقتنص أقصى مكسب، لكنه قد يضر بالعلاقة ويستفز الطرف الآخر.", "pair_key": "p4" },
    { "text": "مفيد إذا كان الوضع الحالي مقبولاً أو المخاطرة عالية، لكنه يضيع الفرص.", "pair_key": "p1" },
    { "text": "يحفظ العلاقة سريعاً، لكنه قد يضحي بمصلحتك الشخصية.", "pair_key": "p2" }
  ]
}
```

---

بهذا الشكل يمكنك أخذ أسئلة أي حلقة (اختيار من متعدد، صح/خطأ، توصيل)، ووضعها في `questions`، ثم إرسالها مع `lesson_id` في مسار الـ endpoint ليتم إنشاء الأسئلة والخيارات وربط الإجابات الصحيحة تلقائياً.
