## ✅ الخطوات التالية

### الخطوة 1: اختبار توليد شهادة تجريبية

```bash
# اختبار توليد صورة شهادة محددة
php artisan certificates:regenerate-image 11 --force

# أو اختبار مباشر
php artisan tinker
```

```php
$certificate = App\Models\System\Certificate::find(11);
$service = app(\App\Http\Services\System\CertificateService::class);
$imagePath = $service->generateCertificateImage($certificate);
echo "تم إنشاء الشهادة: storage/app/public/{$imagePath}";
```

### الخطوة 2: فحص النتيجة

1. **افتح الملف المولد**:
   ```
   storage/app/public/certificates/{certificate_code}.png
   ```

2. **تحقق من**:
   - ✅ جميع النصوص تظهر بشكل صحيح
   - ✅ المواضع صحيحة
   - ✅ الخطوط العربية تعمل
   - ✅ الألوان صحيحة
   - ✅ المحاذاة صحيحة

3. **إذا كانت المواضع خاطئة**:
   - افتح صورة القالب في برنامج تصميم
   - حدد المواضع الدقيقة (X, Y)
   - عدّل الكود في `generateCertificateImage()`

### الخطوة 3: تعديل المواضع (إذا لزم)

إذا كانت المواضع غير صحيحة، عدّل الكود:

```php
// مثال: تعديل موضع اسم المستخدم
$userNameY = 228; // بدلاً من (int)($imageHeight * 0.45)
```

## ⚠️ ملاحظات مهمة

### 1. حجم الصورة
- **الحالي**: 716x507 بكسل (صغير)
- **الموصى به للطباعة**: 2400x1600 بكسل أو أكبر (300 DPI)

**إذا أردت طباعة عالية الجودة**:
- استبدل صورة القالب بصورة أكبر (2400x1600 أو أكبر)
- المواضع ستتعدل تلقائياً لأنها تستخدم نسب مئوية

### 2. الخط العربي
- الخط `itfHuwiyaDisplay-Regular.otf` موجود ويعمل ✅
- الكود محدث لاستخدام هذا الخط ✅

### 3. QR Code
- **حالياً**: SVG (لا يمكن دمجه في PNG بدون imagick)
- **الحلول**:
  - تثبيت imagick extension (لتحويل SVG إلى PNG)
  - أو عرض QR Code بشكل منفصل في الواجهة

### 4. الطباعة
- **للطباعة عالية الجودة**: استخدم صورة قالب بحجم أكبر (2400x1600+)
- **للعرض على الشاشة**: الحجم الحالي (716x507) كافي

## 🆘 حل المشاكل

### المشكلة: النصوص في مواضع خاطئة
**الحل**: 
1. افتح صورة القالب في برنامج تصميم
2. حدد المواضع الدقيقة (X, Y) لكل نص
3. عدّل الكود في `generateCertificateImage()`

### المشكلة: الخطوط العربية لا تظهر
**الحل**: 
- تأكد من أن الخط موجود في `storage/app/fonts/`
- تأكد من أن المسار صحيح في الكود

**الحل**: 
- حدد الألوان الدقيقة من التصميم (HEX codes)
- عدّل الكود في `generateCertificateImage()`
