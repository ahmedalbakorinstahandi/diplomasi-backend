## 🎯 الاختبار الفوري

### اختبار توليد شهادة:

```bash
# إعادة توليد صورة شهادة محددة
php artisan certificates:regenerate-image 11 --force

# أو اختبار مباشر
php artisan tinker
```

```php
$certificate = App\Models\System\Certificate::find(11);
$service = app(\App\Http\Services\System\CertificateService::class);
$imagePath = $service->generateCertificateImage($certificate);
echo "تم إنشاء الشهادة في: storage/app/public/{$imagePath}";
```

### فحص النتيجة:

1. **افتح الملف**:
   ```
   storage/app/public/certificates/{certificate_code}.png
   ```

2. **تحقق من**:
   - ✅ جميع النصوص تظهر
   - ✅ الخطوط العربية تعمل
   - ✅ المواضع صحيحة
   - ✅ الألوان صحيحة
   - ✅ المحاذاة صحيحة

3. **إذا كانت المواضع خاطئة**:
   - افتح صورة القالب في برنامج تصميم (Photoshop/GIMP/Figma)
   - حدد المواضع الدقيقة (X, Y) لكل نص
   - عدّل الكود في `generateCertificateImage()`

## 🔧 التعديلات المحتملة

### 1. تعديل المواضع:

إذا كانت المواضع خاطئة، عدّل الأرقام في `generateCertificateImage()`:

```php
// مثال: تعديل موضع اسم المستخدم
// من: $userNameY = (int)($imageHeight * 0.45);
// إلى: $userNameY = 228; // موضع دقيق بالبكسل

// أو استخدم نسب مختلفة:
$userNameY = (int)($imageHeight * 0.42); // 42% بدلاً من 45%
```

### 2. تعديل الأحجام:

```php
// مثال: تكبير اسم المستخدم
$font->size(60); // بدلاً من 52
```

### 3. تعديل الألوان:

```php
// مثال: تغيير لون اسم الكورس
$font->color('#FFA500'); // برتقالي بدلاً من #D4A017
```

### 4. إضافة نص جديد:

```php
// مثال: إضافة "ختم الإدارة:" في الأسفل الأيسر
$stampText = "ختم الإدارة:";
$stampX = (int)($imageWidth * 0.15); // 15% من العرض
$stampY = (int)($imageHeight * 0.85); // 85% من الارتفاع

$image->text($stampText, $stampX, $stampY, function ($font) use ($arabicFontPath) {
    if ($arabicFontPath) {
        $font->filename($arabicFontPath);
    }
    $font->size(18);
    $font->color('#1a1a5e');
    $font->align('left');
    $font->valign('middle');
});
```
